# Flock

This extension adds the Flock skill for building source-grounded knowledge graphs, auditing evidence, and comparing synthetic social scenarios. Use the `flock` skill when a user asks for graph research, source review, or scenario exploration. The active Qwen Code session supplies reasoning; Flock's Python helper validates and stores data in the selected workspace. Flock does not collect provider credentials. Invoke the skill as `/flock:flock`. Qwen account sign-in, model/provider configuration, and usage limits remain part of the user's Qwen Code setup.
