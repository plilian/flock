# Flock

This extension adds the Flock skill for building source-grounded knowledge graphs and exploring synthetic social scenarios. Use the `flock` skill when a user asks for graph research or simulation. The active Qwen Code session supplies reasoning; Flock's Python helper only validates and stores data in the selected workspace. Flock does not collect provider credentials. Invoke the skill as `/flock:flock`. Qwen account sign-in, model/provider configuration, and usage limits remain part of the user's Qwen Code setup.
