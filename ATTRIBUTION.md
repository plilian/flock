Flock is an independently maintained, substantially modified derivative of [MiroFish](https://github.com/666ghj/MiroFish), an open-source project created by its original contributors. The new Flock release replaces the prior web-app delivery with a Codex plugin workflow and introduces a project-owned SQLite graph and social interaction store.
