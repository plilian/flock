# Attribution and project lineage

Flock is an independently maintained, substantially modified derivative of [MiroFish](https://github.com/666ghj/MiroFish), an open-source project created by its original contributors. Flock replaces the prior web-app delivery and Zep-backed graph workflow with native packages for multiple AI agent hosts and a project-owned SQLite graph and social interaction store. Model reasoning runs through each user's active host session and that host's configured model access. Flock requires no separate Flock model-service key or Zep key; host-specific authentication or provider credentials may still be required. Each host's account policies, usage, and limits remain the responsibility of that user.
