# Attribution and project lineage

Flock is an independently maintained, substantially modified derivative of [MiroFish](https://github.com/666ghj/MiroFish), an open-source project created by its original contributors. Flock replaces the prior web-app delivery and Zep-backed graph workflow with a Codex plugin workflow and a project-owned SQLite graph and social interaction store. Model reasoning runs through each user's own ChatGPT account signed into Codex; no separate LLM-provider API key or Zep key is required. Codex account usage and limits remain the responsibility of that user.
