# Flock

This extension adds the Flock skill for building source-grounded knowledge graphs and exploring synthetic social scenarios. Use the `flock` skill when a user asks for graph research or simulation. The active Gemini CLI session supplies reasoning; Flock's Python helper only validates and stores data in the selected workspace. Flock does not collect provider credentials. Google authentication, model availability, and usage limits remain part of the user's Gemini CLI setup.
