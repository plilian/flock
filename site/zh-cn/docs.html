01 / 安装

为你的平台安装

Flock 为每个受支持的智能体平台提供原生插件或扩展包。每个软件包都包含相同的工作流技能和不调用模型的 Python 辅助工具。平台会话负责推理；辅助工具负责验证并保存图谱和模拟数据。

所有软件包均可直接从公开 GitHub 仓库安装。Flock 不提供托管模型，也不需要 Flock API 密钥。请按所选平台的说明登录或配置；服务商选项和用量限制因平台而异。

共同要求

  • Python 3.11 或更高版本，并可在平台环境中访问工作区和终端。
  • 用于从公开仓库安装软件包的 Git。
  • Flock 数据目录： .flock/
  • 你自己的受支持平台安装和模型访问权限。Flock 不会共享开发者的账户。

01 / CODEX · 原生插件

Codex

添加 Flock 插件市场并安装插件：

codex plugin marketplace add plilian/flock
codex plugin add flock@flock

打开或重启 Codex，然后让它使用 Flock，或调用以下技能： $flock 技能。

02 / CLAUDE CODE · 原生插件

Claude Code

在 Claude Code 终端中添加 Flock 插件市场并安装：

claude plugin marketplace add plilian/flock
claude plugin install flock@flock

如有需要，请重启或重新加载 Claude Code，打开工作区，然后让 Claude 使用以下技能： flock 技能。

03 / GEMINI CLI · 原生扩展

Gemini CLI

从仓库 URL 安装 Flock：

gemini extensions install https://github.com/plilian/flock

如提示，请重启 CLI，然后让 Gemini CLI 使用 Flock 技能。Gemini CLI 的身份验证和模型访问由你的 Google/Gemini 设置决定。

04 / QWEN CODE · 原生扩展

Qwen Code

从仓库 URL 安装 Flock：

qwen extensions install https://github.com/plilian/flock

如有提示，请重启 CLI，然后调用 /flock:flock 或者让 Qwen Code 使用该技能。Qwen 登录、服务商配置和用量限制由 Qwen Code 设置管理。

05 / DEEPSEEK HARNESS · 开发者预览版

DeepSeek Harness

Harness 是独立的开发者预览版插件宿主。克隆仓库，并将 Flock 安装到 Harness 配置中：

git clone https://github.com/plilian/flock.git
cd flock
dsh plugin --profile web add ./plugins/deepseek-harness

此软件包仅适用于 DeepSeek Harness。它不是 DeepSeek 聊天网站的插件，也不会调用 DeepSeek API。Harness 的模型访问取决于其支持的服务商配置，可能需要单独设置。

这些软件包可从 GitHub 安装，但尚未列入各供应商管理的插件目录。“无需 Flock API 密钥”表示 Flock 没有独立凭据或模型服务；各平台要求的身份验证或服务商配置仍需完成。

02 / 第一个项目

初始化工作区

在希望保存 Flock 数据的工作区中打开平台。放入或附加来源文档，然后向智能体提出请求：

使用 Flock 初始化一个名为“交通研究”的项目。

Flock 将 SQLite 图数据库和运行记录保存在 .flock/ 目录中。每个项目使用单独的工作区文件夹。辅助工具会添加忽略规则，避免图谱和运行数据被意外提交到 Git。来源文档保留在原位置；Flock 只保存来源名称和引用，不会复制全文。

03 / 工作流

从证据到模拟运行

构建图谱

让平台智能体从选定资料中提取图谱。当前模型识别本体、实体和关系；Flock 验证来源引用并存入 SQLite 图谱。你可以通过 Mermaid 图、搜索或图谱统计进行检查。

使用 Flock 从 ./sources 构建知识图谱，并展示最重要的关系。

创建合成群体

描述要研究的群体和问题。平台模型根据图谱实体生成个人资料，并标明哪些内容是推测而非来源事实。

探索场景

选择类似 Reddit 或 Twitter 的讨论方式，设定场景和轮数，并在运行前检查资料中的假设。平台模型生成每轮行动；Flock 验证行动并记录信息流、反应和互动次数。

复核与访谈

使用记录的时间线编写报告、回答问题，或模拟采访合成智能体。报告会将统计结果与定性解读分开。

查看模拟运行

每轮结束后，Flock 会更新以下位置的交互式 HTML 快照： .flock/runs/<run_id>/visualization.html。你可以浏览或播放轮次、查看合成资料、追踪回复和反应、搜索信息流并下载运行数据。它可直接在浏览器中打开，不会发起外部请求。

04 / EVIDENCE AUDIT

追溯主张的来源

将图谱中的实体和关系标记为 observed, inferred、或 assumption。较早的记录在审核前保持 unclassified 。审计会检查来源引用覆盖情况、缺失的定位信息或摘录、未使用的来源以及未分类的图谱记录。

python <helper> --workspace . graph audit

辅助工具会将 JSON 审计保存到本地目录： .flock/audits/。让当前平台核对引用摘录与来源文档，找出分歧和缺失的观点，并在审计文件旁写下简洁的 Markdown 复核报告。引用意味着可以追溯，并不能验证主张或证明来源准确。

模拟中的事实类帖子可以带有图谱来源引用 evidence_refs。Flock 会验证这些 ID，并将原始来源名称、定位信息和简短摘录与事件一同保存，因此回放时可以查看合成智能体的事实主张来自哪里。

05 / SCENARIO LAB

比较基线与替代方案

Scenario Lab 让每个变体和重复实验使用相同的合成资料、平台、轮数和空信息流。一次只更改一个主要条件，例如是否出现更正信息或版主是否介入。每次运行的历史彼此独立。

将实验规格保存到 .flock/staging/experiment.json ，并包含研究问题、共享的智能体列表、2–6 个变体、一个基线，以及每个变体 1–5 次重复。每个变体都要写明场景和假设。模型运行次数随变体数 × 重复数 × 轮数 × 智能体数增长。

python <helper> --workspace . scenario validate --spec .flock/staging/experiment.json
python <helper> --workspace . scenario create --spec .flock/staging/experiment.json
python <helper> --workspace . scenario status --id <experiment_id>
python <helper> --workspace . scenario compare --id <experiment_id>
python <helper> --workspace . scenario visualize --id <experiment_id>
python <helper> --workspace . scenario save-report --id <experiment_id> --input .flock/staging/report.md

比较报告会列出行动次数、参与度、立场数量、每轮活动及相对基线的差异。它展示各项指标在已保存重复实验中的中位数、最小值和最大值，并在以下位置生成交互式比较页面： .flock/experiments/<experiment_id>/comparison.html，并提供每次运行的回放链接。

重复实验的范围仅汇总这些合成运行，不是置信区间或现实结果概率。请将统计次数与平台解读分开，并在结论中引用图谱来源和运行／事件 ID。

06 / 模拟引擎

运行机制

Flock 将模型推理与持久化状态分开。平台当前使用的模型读取所选证据和资料，提出智能体行动并撰写分析。Python 辅助工具保存图谱记录、检查行动格式、推进轮次并统计活动。

  • 类似 Reddit 的行动： 发帖、评论、赞成票、反对票和加入社群。
  • 类似 Twitter 的行动： 发帖、回复、点赞、转发和关注。
  • 保存的内容： 证据状态和引用、结构审计文件、智能体资料、逐轮事件、事实行动的已验证来源、场景实验、交互式 HTML 对比、单次运行回放和 Markdown 报告。

Flock 模拟是一种结构化思想实验，不是对真实人群的观察、民意调查或预测。结果取决于所选模型、提示、来源质量、资料和设置。

快速问答

关于 Flock 的常见问题

Flock 是什么？

Flock 是开源 AI 智能体插件工作流，可用于构建有来源依据的知识图谱、审查证据、创建合成群体和探索社交场景。项目图谱和模拟运行数据保存在工作区本地的 SQLite 数据库中。

Flock 能预测真实人群的行为吗？

不能。Flock 使用合成智能体运行结构化思想实验。结果不是民意调查、对真实人群的观察或预测，重复实验范围也不代表现实概率。

Flock 需要 AI API 密钥或 Zep 吗？

Flock 没有独立 API 密钥、模型服务、托管图谱服务，也不依赖 Zep。模型访问由所选平台自身的登录和服务商设置管理；该平台的要求、套餐和用量限制仍然适用。

Flock 支持哪些语言？

Flock 技能支持英语、日语、简体中文（zh-CN）和西班牙语。它会使用你所用的语言回复，并以该语言撰写研究问题、合成智能体内容、审计和报告。命令、架构键、ID 和固定枚举值保持不变。

哪些 AI 智能体平台可以使用 Flock？

Flock 为 Codex、Claude Code、Gemini CLI 和 Qwen Code 提供可安装软件包。DeepSeek Harness 有独立的开发者预览包；它不集成 DeepSeek 聊天网站或 API。

Flock 的图谱和模拟数据保存在哪里？

Flock 将 SQLite 图谱、证据审计、场景实验、运行历史和可视化结果保存在 .flock/ 目录中，该目录位于你选择的工作区内。Flock 网站不会收到项目数据。

07 / 隐私与数据

你的工作区，你的平台

  • 所选平台通过用户自己的活动会话和服务商设置处理来源摘录与提示。其账户设置、模型政策、套餐和限制均适用。
  • Flock Python 辅助工具不会发起网络或模型调用，也不会读取平台凭据。它会将图谱数据、证据审计、场景实验、可视化结果和报告保存在所选工作区内的 .flock/ 文件夹中。
  • Flock 不需要独立的服务商 API 密钥、Zep 密钥或 Flock 账户。某些平台配置可能需要平台自己的服务商凭据。
  • 公开网站提供信息和安装说明。模拟在每位用户的工作区运行；Flock 网站服务器不会收到项目资料、图谱或运行历史。
  • 分享资料或生成的图谱前，请检查工作区备份和 Git 设置。

08 / 故障排查

遇到问题时

平台找不到 Flock

确认软件包已成功安装并重启平台。在 Codex 中运行 codex plugin list；在 Claude Code 中查看 /plugin；在 Gemini CLI 和 Qwen Code 中查看扩展列表。DeepSeek Harness 插件仍处于开发者预览阶段。

Python 缺失或版本过旧

安装 Python 3.11 或更高版本，并确认 python 在平台运行环境中可用。无需安装其他图谱或数据库软件包。

图谱验证报告缺少来源

请确认每个实体和关系引用使用的 source_id 存在于候选图谱的 sources 数组中。导入前请重新验证图谱。

卸载 Flock

使用平台的插件或扩展管理器卸载 Flock。卸载不会删除工作区数据。请先备份，或确认不再需要相关图谱和运行数据，然后再删除 .flock/ 。

09 / 项目

许可证与来源说明

Flock 根据 AGPL-3.0进行分发。它是对开源项目 MiroFish 的大幅修改版，由独立团队维护。Flock 用面向受支持智能体平台的原生软件包和工作区本地 SQLite 图谱，取代了早期网页应用及基于 Zep 的图谱工作流。Flock 与 MiroFish 及其维护者没有关联，也未获其认可。详情请参阅 归属声明 了解项目来源。
