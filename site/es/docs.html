01 / INSTALACIÓN

Instala Flock en tu agente

Flock se distribuye como complemento o extensión nativa para cada agente compatible. Todos los paquetes incluyen la misma habilidad de flujo de trabajo y un asistente Python que no usa modelos. La sesión activa del agente razona; el asistente valida y guarda los datos del grafo y la simulación.

Todos los paquetes se instalan directamente desde el repositorio público de GitHub. Flock no ofrece un modelo alojado ni requiere una clave API de Flock. Inicia sesión o configura el agente según sus instrucciones; los proveedores disponibles y los límites varían.

Requisitos comunes

  • Python 3.11 o posterior y acceso al espacio de trabajo y la terminal del agente.
  • Git para instalar paquetes desde este repositorio público.
  • Carpeta de datos de Flock: .flock/
  • Tu propia instalación de un agente compatible y acceso a un modelo. Flock nunca comparte la cuenta del desarrollador.

01 / CODEX · COMPLEMENTO NATIVO

Codex

Añade el marketplace de Flock e instala el complemento:

codex plugin marketplace add plilian/flock
codex plugin add flock@flock

Abre o reinicia Codex y pídele que use Flock o invoca la habilidad $flock .

02 / CLAUDE CODE · COMPLEMENTO NATIVO

Claude Code

Añade el marketplace de Flock e instala desde una terminal de Claude Code:

claude plugin marketplace add plilian/flock
claude plugin install flock@flock

Si hace falta, reinicia Claude Code; abre tu espacio de trabajo y pídele a Claude que use la habilidad flock .

03 / GEMINI CLI · EXTENSIÓN NATIVA

Gemini CLI

Instala Flock desde la URL del repositorio:

gemini extensions install https://github.com/plilian/flock

Si se te solicita, reinicia la CLI y pide a Gemini CLI que use la habilidad de Flock. La autenticación y el acceso a modelos dependen de tu configuración de Google/Gemini.

04 / QWEN CODE · EXTENSIÓN NATIVA

Qwen Code

Instala Flock desde la URL del repositorio:

qwen extensions install https://github.com/plilian/flock

Si se te solicita, reinicia la CLI y ejecuta /flock:flock o pide a Qwen Code que use esa habilidad. El inicio de sesión, los proveedores y los límites de uso se configuran en Qwen Code.

05 / DEEPSEEK HARNESS · VISTA PREVIA

DeepSeek Harness

Harness es un host de complementos independiente en vista previa para desarrolladores. Clona el repositorio e instala Flock en un perfil de Harness:

git clone https://github.com/plilian/flock.git
cd flock
dsh plugin --profile web add ./plugins/deepseek-harness

Este paquete es solo para DeepSeek Harness. No es un complemento del sitio de chat de DeepSeek y no llama a la API de DeepSeek. El acceso a modelos depende de los proveedores compatibles con Harness y puede requerir una configuración adicional.

Estos paquetes se instalan desde GitHub, pero no aparecen en los directorios de complementos administrados por cada proveedor. «Flock no requiere clave API» significa que no tiene credenciales ni servicio de modelos propios; cada agente puede seguir requiriendo su autenticación o configuración de proveedor.

02 / PRIMER PROYECTO

Inicializar un espacio de trabajo

Abre el agente en el espacio donde quieras guardar los datos de Flock. Coloca o adjunta los documentos fuente y pide al agente:

Usa Flock para inicializar un proyecto llamado «Estudio de transporte».

Flock guarda la base de datos SQLite del grafo y los registros de ejecución en la carpeta .flock/ . Usa una carpeta de trabajo distinta para cada proyecto. El asistente añade una regla de exclusión para evitar que el grafo y las ejecuciones se incluyan por error en Git. Los documentos permanecen en su ubicación; Flock guarda sus nombres y citas, no copias completas.

03 / FLUJOS DE TRABAJO

De la evidencia a una ejecución

Construir el grafo

Pide al agente que extraiga un grafo de las fuentes seleccionadas. El modelo activo identifica la ontología, las entidades y las relaciones; Flock valida y guarda las referencias en su grafo SQLite. Inspecciónalo con un diagrama Mermaid, búsquedas o estadísticas.

Usa Flock para crear un grafo de conocimiento a partir de ./sources y mostrar sus relaciones principales.

Crear una población sintética

Describe la población y la pregunta que quieres explorar. El modelo del agente crea perfiles basados en entidades del grafo y marca como supuestos los detalles que no proceden de las fuentes.

Explorar un escenario

Elige un debate al estilo de Reddit o Twitter, define el escenario y el número de rondas, y revisa los supuestos de los perfiles antes de ejecutarlo. El modelo genera las acciones de cada ronda; Flock las valida y registra publicaciones, reacciones e interacciones.

Revisar y entrevistar

Usa la cronología para redactar un informe, responder preguntas o simular una entrevista con un agente sintético. Los informes separan los recuentos calculados de la interpretación cualitativa.

Visualizar la ejecución

Después de cada ronda, Flock actualiza una vista HTML interactiva en .flock/runs/<run_id>/visualization.html. Avanza o reproduce las rondas, consulta perfiles sintéticos, sigue respuestas y reacciones, busca en el feed y descarga los datos. Se abre directamente en el navegador y no realiza solicitudes externas.

04 / EVIDENCE AUDIT

Rastrear afirmaciones hasta sus fuentes

Etiqueta cada entidad y relación del grafo como observed, inferred, o assumption. Los registros anteriores permanecen como unclassified hasta revisarlos. La auditoría comprueba la cobertura de referencias, las ubicaciones o citas que faltan, las fuentes sin usar y los registros sin clasificar.

python <helper> --workspace . graph audit

El asistente guarda una auditoría JSON local en .flock/audits/. Pide al agente que contraste las citas con los documentos seleccionados, detecte desacuerdos y perspectivas ausentes, y escriba una revisión breve en Markdown junto al archivo. Una cita permite rastrear la fuente, pero no verifica una afirmación ni demuestra que la fuente sea correcta.

Durante las simulaciones, las publicaciones factuales pueden incluir evidence_refs. Flock valida esos identificadores y guarda el nombre original de la fuente, su ubicación y un fragmento breve junto al evento. Así, la reproducción muestra el origen de cada afirmación factual sintética.

05 / SCENARIO LAB

Comparar una referencia con alternativas

Scenario Lab inicia cada variante y repetición con los mismos perfiles sintéticos, plataforma, número de rondas y feed vacío. Cambia una condición principal cada vez, como mostrar una corrección o incorporar a un moderador. Mantén separadas las ejecuciones.

Guarda la especificación del experimento en .flock/staging/experiment.json con una pregunta de investigación, una lista de agentes compartida, entre 2 y 6 variantes, una referencia y de 1 a 5 repeticiones por variante. Cada variante incluye el escenario y sus supuestos explícitos. El total de ejecuciones del modelo aumenta según variantes × repeticiones × rondas × agentes.

python <helper> --workspace . scenario validate --spec .flock/staging/experiment.json
python <helper> --workspace . scenario create --spec .flock/staging/experiment.json
python <helper> --workspace . scenario status --id <experiment_id>
python <helper> --workspace . scenario compare --id <experiment_id>
python <helper> --workspace . scenario visualize --id <experiment_id>
python <helper> --workspace . scenario save-report --id <experiment_id> --input .flock/staging/report.md

La comparación presenta recuentos de acciones, participación, posturas, actividad por ronda y diferencias respecto a la referencia. Muestra la mediana y los valores mínimo/máximo de cada métrica y crea una comparación interactiva en .flock/experiments/<experiment_id>/comparison.html, con enlaces a la reproducción de cada ejecución.

Los rangos de repetición solo resumen estas ejecuciones sintéticas. No son intervalos de confianza ni probabilidades de resultados reales. Separa los recuentos calculados de la interpretación del agente y cita las fuentes del grafo y los identificadores de ejecución y evento.

06 / MOTOR DE SIMULACIÓN

Cómo funciona una ejecución

Flock separa el razonamiento del modelo del estado persistente. El modelo activo del agente lee las evidencias y los perfiles, propone acciones y redacta el análisis. El asistente Python guarda el grafo, valida el formato de las acciones, avanza las rondas y calcula la actividad.

  • Acciones al estilo de Reddit: publicaciones, comentarios, votos positivos y negativos, y uniones a comunidades.
  • Acciones al estilo de Twitter: publicaciones, respuestas, me gusta, republicaciones y seguimientos.
  • Datos guardados: estados y citas de evidencia, auditorías estructurales, perfiles de agentes, eventos por ronda, referencias de fuentes validadas, experimentos de escenarios, comparaciones HTML interactivas, reproducciones e informes Markdown.

Una simulación de Flock es un experimento mental estructurado. No observa a personas reales ni es una encuesta o un pronóstico. Los resultados dependen del modelo, las instrucciones, las fuentes, los perfiles y la configuración.

RESPUESTAS RÁPIDAS

Preguntas frecuentes sobre Flock

¿Qué es Flock?

Flock es un flujo de trabajo de complemento de agente de IA de código abierto para crear grafos de conocimiento basados en fuentes, revisar evidencias, generar poblaciones sintéticas y explorar escenarios sociales. Guarda los grafos y las ejecuciones localmente en una base de datos SQLite del espacio de trabajo.

¿Flock predice qué harán las personas reales?

No. Flock ejecuta experimentos mentales estructurados con agentes sintéticos. Los resultados no son encuestas, observaciones de personas reales ni pronósticos; los rangos tampoco representan probabilidades del mundo real.

¿Flock necesita una clave API de IA o Zep?

Flock no requiere una clave API propia, un servicio de modelos o grafos alojado ni Zep. El acceso al modelo se gestiona con la cuenta y el proveedor del agente elegido; siguen aplicándose sus requisitos, planes y límites.

¿Qué idiomas admite Flock?

La habilidad de Flock admite inglés, japonés, chino simplificado (zh-CN) y español. Responde en el idioma que uses y redacta las preguntas de investigación, el contenido sintético, las auditorías y los informes en ese idioma. Los comandos, las claves de esquema, los identificadores y los valores enumerados no cambian.

¿Qué agentes de IA admiten Flock?

Flock ofrece paquetes instalables para Codex, Claude Code, Gemini CLI y Qwen Code. El paquete independiente para DeepSeek Harness está en vista previa para desarrolladores; no se integra con el sitio de chat ni la API de DeepSeek.

¿Dónde se guardan los grafos y los datos de simulación?

Flock guarda el grafo SQLite, las auditorías de evidencia, los experimentos, el historial y las visualizaciones en la carpeta .flock/ del espacio de trabajo que elijas. El sitio web de Flock no recibe los datos del proyecto.

07 / PRIVACIDAD Y DATOS

Tu espacio de trabajo, tu agente

  • El agente procesa fragmentos de fuentes e instrucciones en la sesión y con el proveedor del propio usuario. Se aplican la configuración de su cuenta, las políticas del modelo, el plan y los límites.
  • El asistente Python de Flock no realiza llamadas de red o a modelos ni lee credenciales del agente. Guarda los grafos, las auditorías, los experimentos, las visualizaciones y los informes en la carpeta .flock/ del espacio de trabajo seleccionado.
  • Flock no necesita una clave API de proveedor, una clave de Zep ni una cuenta de Flock. Algunas configuraciones del agente pueden requerir sus propias credenciales.
  • El sitio público ofrece información e instrucciones de instalación. Las simulaciones se ejecutan en el espacio de trabajo de cada usuario; el servidor de Flock no recibe las fuentes, los grafos ni el historial.
  • Revisa las copias de seguridad y la configuración de Git antes de compartir fuentes o grafos generados.

08 / SOLUCIÓN DE PROBLEMAS

Si algo no funciona

El agente no encuentra Flock

Comprueba que el paquete se instaló correctamente y reinicia el agente. En Codex, consulta codex plugin list; en Claude Code, consulta /plugin; en Gemini CLI y Qwen Code, consulta la lista de extensiones. Los complementos de DeepSeek Harness siguen en vista previa para desarrolladores.

Falta Python o su versión es antigua

Instala Python 3.11 o posterior y asegúrate de que python esté disponible en el entorno del agente. No hace falta instalar paquetes adicionales de grafos o bases de datos.

La validación del grafo indica que falta una fuente

Comprueba que cada referencia de entidad y relación usa source_id que exista en el arreglo sources del grafo candidato. Vuelve a validar antes de importar.

Desinstalar Flock

Desinstala Flock desde el administrador de complementos o extensiones del agente. La desinstalación no elimina los datos del espacio de trabajo. Borra .flock/ solo después de hacer una copia o confirmar que ya no necesitas esos grafos ni ejecuciones.
