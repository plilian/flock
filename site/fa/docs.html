FLOCK / راهنما

Flock برای
فضای کاری خودت.

بستهٔ مخصوص محیط AI خودت را نصب کن و با منبع‌ها و سناریوهای خودت کار کن. Flock روی دستگاه و فضای کاری خودت اجرا می‌شود؛ سرویس شبیه‌سازی میزبانی‌شده نیست.

توی این صفحه نصب اولین پروژه روندهای کار بررسی شواهد آزمایش سناریوها سازوکار شبیه‌سازی سؤال‌های رایج حریم خصوصی و داده‌ها رفع مشکل مجوز

۰۱ / نصب

نصب برای محیط AI خودت

برای هر محیط AI، Flock به شکل پلاگین یا افزونهٔ اختصاصی ارائه می‌شود. هر بسته همان مهارت کاری و ابزار Python را دارد؛ ابزار Python خودش از مدل استفاده نمی‌کند. مدلِ نشست فعال تحلیل را انجام می‌دهد و ابزار، گراف و داده‌های شبیه‌سازی را بررسی و ذخیره می‌کند.

همهٔ بسته‌ها مستقیم از مخزن عمومی GitHub نصب می‌شوند. Flock نه مدل میزبانی‌شده دارد و نه برای خودش کلید API می‌خواهد. با حساب خودت وارد محیط AI انتخابی شو و همان‌جا دسترسی مدل را تنظیم کن؛ روش دسترسی و سقف مصرف به هر محیط بستگی دارد.

پیش‌نیازهای مشترک

  • Python نسخهٔ ۳٫۱۱ یا جدیدتر و دسترسی به فضای کاری و ترمینال در محیط AI.
  • Git برای نصب بسته‌ها از این مخزن عمومی.
  • پوشهٔ داده‌های Flock: .flock/
  • نصب محیط AI پشتیبانی‌شده و دسترسی مدل با حساب خودت. Flock از حساب سازنده استفاده نمی‌کند و آن را با کسی به اشتراک نمی‌گذارد.

۰۱ / CODEX · پلاگین اختصاصی

Codex

فهرست پلاگین‌های Flock را اضافه کن و پلاگین را نصب کن:

codex plugin marketplace add plilian/flock
codex plugin add flock@flock

Codex را باز کن یا یک‌بار راه‌اندازی مجدد کن؛ بعد از آن بخواه از Flock استفاده کند یا مهارت $flock را اجرا کند.

۰۲ / CLAUDE CODE · پلاگین اختصاصی

Claude Code

فهرست Flock را اضافه کن و از ترمینال Claude Code نصبش کن:

claude plugin marketplace add plilian/flock
claude plugin install flock@flock

اگر لازم بود Claude Code را دوباره باز یا بارگذاری کن، وارد فضای کاری‌ات شو و از Claude بخواه مهارت flock را اجرا کند.

۰۳ / GEMINI CLI · افزونهٔ اختصاصی

Gemini CLI

Flock را از نشانی مخزن نصب کن:

gemini extensions install https://github.com/plilian/flock

اگر پیامی دیدی، CLI را دوباره اجرا کن؛ بعد از Gemini CLI بخواه از مهارت Flock استفاده کند. ورود و دسترسی مدل طبق تنظیمات Google/Gemini خودت است.

۰۴ / QWEN CODE · افزونهٔ اختصاصی

Qwen Code

Flock را از نشانی مخزن نصب کن:

qwen extensions install https://github.com/plilian/flock

اگر پیام داده شد CLI را دوباره اجرا کن، بعد این مهارت را اجرا کن: /flock:flock یا از Qwen Code بخواه آن مهارت را اجرا کند. ورود به حساب، تنظیم سرویس‌دهنده و محدودیت مصرف را خود Qwen Code مدیریت می‌کند.

۰۵ / DEEPSEEK HARNESS · پیش‌نمایش توسعه‌دهندگان

DeepSeek Harness

Harness یک محیط جداگانه برای اجرای پلاگین‌هاست و نسخهٔ Flock برای آن هنوز در مرحلهٔ پیش‌نمایش توسعه‌دهندگان است. مخزن را دریافت کن و Flock را در یکی از پروفایل‌های Harness نصب کن:

git clone https://github.com/plilian/flock.git
cd flock
dsh plugin --profile web add ./plugins/deepseek-harness

این بسته فقط برای DeepSeek Harness است؛ پلاگین سایت گفت‌وگوی DeepSeek نیست و API آن را هم صدا نمی‌زند. دسترسی به مدل به سرویس‌دهنده‌هایی بستگی دارد که Harness پشتیبانی می‌کند و شاید نیاز به تنظیم جداگانه داشته باشد.

این بسته‌ها را می‌توان از GitHub نصب کرد؛ فعلاً در فهرست رسمی پلاگین‌های شرکت‌های سازنده قرار ندارند. «نداشتن کلید API برای Flock» یعنی Flock حساب یا سرویس مدل جداگانه ندارد؛ ورود به حساب یا تنظیم سرویس‌دهنده‌ای که محیط AI خودت لازم دارد همچنان برقرار است.

۰۲ / اولین پروژه

ساخت پروژه در فضای کاری

محیط AI را در همان فضایی باز کن که می‌خواهی داده‌های Flock آنجا بماند. اسناد منبع را اضافه کن، بعد از عامل آن بخواه:

با Flock پروژه‌ای به نام «بررسی رفت‌وآمد شهری» بساز.

Flock پایگاه دادهٔ گراف SQLite و سابقهٔ اجراها را در پوشهٔ .flock/ نگه می‌دارد. برای هر پروژه از یک فضای کاری جدا استفاده کن. ابزار Flock یک قانون ignore اضافه می‌کند تا داده‌های گراف و اجراها تصادفی وارد Git نشوند. اسناد منبع همان‌جایی می‌مانند که گذاشته‌ای؛ Flock فقط نام منبع و ارجاع را ذخیره می‌کند، نه یک نسخهٔ کامل از سند.

۰۳ / روندهای کار

از شواهد تا اجرای شبیه‌سازی

ساخت گراف

از عامل محیط AI بخواه از منبع‌های انتخابی گراف بسازد. مدل فعال، ساختار، موجودیت‌ها و ارتباط‌ها را پیدا می‌کند؛ Flock آن‌ها را بررسی می‌کند و ارجاع به منبع‌ها را در گراف SQLite نگه می‌دارد. بعد می‌توانی گراف را با نمودار Mermaid، جست‌وجو یا آمار بررسی کنی.

با Flock از ./sources گراف دانش بساز و مهم‌ترین ارتباط‌هایش را نشان بده.

ساخت جامعهٔ شبیه‌سازی‌شده

جامعه و سؤالی را که می‌خواهی بررسی کنی توضیح بده. مدل محیط AI بر پایهٔ موجودیت‌های گراف، شخصیت‌ها را می‌سازد و چیزهایی را که فرض هستند از واقعیت‌های منبع جدا علامت می‌زند.

بررسی یک سناریو

نوع گفت‌وگو را شبیه Reddit یا Twitter انتخاب کن، سناریو و تعداد دورها را مشخص کن و قبل از اجرا فرض‌های مربوط به شخصیت‌ها را ببین. مدل میزبان رفتار هر دور را می‌سازد؛ Flock آن‌ها را بررسی می‌کند و نوشته‌ها، واکنش‌ها و تعداد تعامل‌ها را ثبت می‌کند.

مرور و گفت‌وگو

از روی خط زمانی ثبت‌شده گزارش بنویس، به سؤال‌ها جواب بده یا با یک عامل شبیه‌سازی‌شده گفت‌وگو کن. در گزارش، آمار محاسبه‌شده از برداشت و تحلیل جدا می‌ماند.

دیدن اجرای شبیه‌سازی

بعد از هر دور، Flock یک نمای HTML تعاملی را در مسیر .flock/runs/<run_id>/visualization.htmlبه‌روز می‌کند. می‌توانی دورها را عقب‌وجلو کنی یا پخش کنی، شخصیت‌ها و واکنش‌ها را ببینی، نوشته‌ها را جست‌وجو کنی و داده‌های اجرا را بگیری. این فایل مستقیم در مرورگر باز می‌شود و به سایت دیگری وصل نمی‌شود.

۰۴ / بررسی شواهد

پیدا کردن منبع هر ادعا

هر موجودیت و ارتباط گراف را با یکی از این برچسب‌ها مشخص کن: observed, inferred، یا assumption. موارد قدیمی تا زمان بررسی با برچسب unclassified می‌مانند. بررسی شواهد نشان می‌دهد کدام موردها منبع دارند، نشانی یا بخشی از منبع کم است، منبعی استفاده نشده یا داده‌ای هنوز دسته‌بندی نشده است.

python <helper> --workspace . graph audit

ابزار Flock نتیجهٔ بررسی را به شکل JSON در مسیر .flock/audits/ذخیره می‌کند. از مدل فعال بخواه نقل‌قول‌ها را با اسناد انتخابی بسنجد، اختلاف‌ها و دیدگاه‌های جاافتاده را پیدا کند و خلاصه‌ای در قالب Markdown کنار فایل بررسی بنویسد. ارجاع فقط مسیر رسیدن به منبع را نشان می‌دهد؛ درستی ادعا یا منبع را ثابت نمی‌کند.

در شبیه‌سازی، نوشته‌هایی که ادعای واقعی دارند می‌توانند ارجاع گرافی evidence_refs داشته باشند. Flock شناسه‌ها را بررسی می‌کند و نام منبع، محل دقیق و بخش کوتاهی از آن را کنار رویداد ذخیره می‌کند؛ بنابراین در بازپخش می‌توان دید ادعای عامل شبیه‌سازی‌شده از کجا آمده است.

۰۵ / آزمایش سناریوها

مقایسهٔ حالت پایه با گزینه‌های دیگر

Scenario Lab هر حالت و تکرارش را با همان شخصیت‌های شبیه‌سازی‌شده، بستر گفت‌وگو، تعداد دورها و صفحهٔ خالی شروع می‌کند. هر بار فقط یک شرط اصلی را عوض کن؛ مثلاً ببین اصلاح یک خبر یا دخالت مدیر چه اثری می‌گذارد. سابقهٔ هر اجرا جدا می‌ماند.

مشخصات آزمایش را اینجا ذخیره کن: .flock/staging/experiment.json در آن سؤال پژوهش، فهرست مشترک شخصیت‌ها، ۲ تا ۶ حالت، یک حالت پایه و ۱ تا ۵ تکرار برای هر حالت را بنویس. هر حالت سناریو و فرض‌های روشن خودش را دارد. تعداد اجراهای مدل با ضرب تعداد حالت‌ها، تکرارها، دورها و شخصیت‌ها بیشتر می‌شود.

python <helper> --workspace . scenario validate --spec .flock/staging/experiment.json
python <helper> --workspace . scenario create --spec .flock/staging/experiment.json
python <helper> --workspace . scenario status --id <experiment_id>
python <helper> --workspace . scenario compare --id <experiment_id>
python <helper> --workspace . scenario visualize --id <experiment_id>
python <helper> --workspace . scenario save-report --id <experiment_id> --input .flock/staging/report.md

گزارش مقایسه، تعداد رفتارها، میزان مشارکت، موضع‌ها، فعالیت هر دور و تفاوت با حالت پایه را نشان می‌دهد. برای هر شاخص، میانه و کمینه/بیشینهٔ تکرارهای ذخیره‌شده را حساب می‌کند و یک صفحهٔ مقایسهٔ تعاملی در مسیر .flock/experiments/<experiment_id>/comparison.htmlمی‌سازد که به بازپخش هر اجرا هم لینک دارد.

بازهٔ تکرارها فقط همین اجراهای شبیه‌سازی‌شده را خلاصه می‌کند؛ نه فاصلهٔ اطمینان آماری است و نه احتمال نتیجه در دنیای واقعی. آمار محاسبه‌شده را از برداشت مدل جدا نگه دار و در نتیجه‌گیری‌ها به منبع‌های گراف و شناسهٔ اجرا و رویداد ارجاع بده.

۰۶ / سازوکار شبیه‌سازی

هر اجرا چطور پیش می‌رود؟

Flock تحلیل مدل را از ذخیره‌سازی داده جدا می‌کند. مدل فعال محیط AI شواهد و شخصیت‌های انتخابی را می‌خواند، رفتار عامل‌ها را پیشنهاد می‌دهد و تحلیل می‌نویسد. ابزار Python داده‌های گراف را نگه می‌دارد، قالب رفتارها را می‌سنجد، دورها را جلو می‌برد و آمار فعالیت را حساب می‌کند.

  • رفتارهای شبیه Reddit: نوشته، نظر، رأی مثبت و منفی و پیوستن به انجمن.
  • رفتارهای شبیه Twitter: نوشته، پاسخ، پسندیدن، بازنشر و دنبال‌کردن.
  • چیزهایی که ذخیره می‌شوند: وضعیت شواهد و ارجاع‌ها، فایل بررسی ساختار، مشخصات عامل‌ها، رویدادهای هر دور، منبع‌های بررسی‌شده برای ادعاهای واقعی، آزمایش سناریوها، مقایسه‌های HTML تعاملی، بازپخش هر اجرا و گزارش‌های Markdown.

شبیه‌سازی Flock یک آزمایش فکری ساختاریافته است؛ نه مشاهدهٔ آدم‌های واقعی است، نه نظرسنجی و نه پیش‌بینی. نتیجه به مدل انتخابی، دستورها، کیفیت منبع‌ها، شخصیت‌ها و تنظیمات بستگی دارد.

جواب‌های کوتاه

سؤال‌های رایج دربارهٔ Flock

Flock چیست؟

Flock یک ابزار متن‌باز برای پلاگین‌های هوش مصنوعی است: از منبع‌هایی که می‌دهی گراف دانش می‌سازد، شواهد را بررسی می‌کند، شخصیت‌های شبیه‌سازی‌شده می‌سازد و سناریوهای اجتماعی را می‌سنجد. گراف و اجراها در پایگاه SQLite فضای کاری خودت ذخیره می‌شوند.

Flock می‌تواند رفتار آدم‌های واقعی را پیش‌بینی کند؟

نه. Flock با عامل‌های شبیه‌سازی‌شده آزمایش فکری انجام می‌دهد. نتیجه‌ها نظرسنجی، مشاهدهٔ آدم‌های واقعی یا پیش‌بینی نیستند و بازهٔ تکرارها هم احتمال اتفاق‌های واقعی را نشان نمی‌دهد.

برای Flock باید کلید API هوش مصنوعی یا Zep داشته باشم؟

نه. Flock برای مدل زبانی کلید API جداگانه نمی‌خواهد و به Zep وابسته نیست؛ گراف خودش را هم در SQLite می‌سازد. مدل از حساب و دسترسی محیط AI خودت استفاده می‌کند. هر هزینه یا محدودیت مصرفی، طبق پلن همان محیط است.

Flock از چه زبان‌هایی پشتیبانی می‌کند؟

مهارت Flock از انگلیسی، ژاپنی، چینی ساده‌شده، اسپانیایی و فارسی پشتیبانی می‌کند. جواب‌ها، سؤال‌های پژوهش، محتوای شخصیت‌های شبیه‌سازی‌شده، بررسی‌ها و گزارش‌ها را به زبان خودت می‌نویسد؛ دستورها، کلیدهای ساختار داده و شناسه‌ها تغییر نمی‌کنند.

Flock را در کدام محیط‌های هوش مصنوعی می‌توانم استفاده کنم؟

برای Codex، Claude Code، Gemini CLI و Qwen Code بستهٔ قابل نصب Flock وجود دارد. بستهٔ جداگانهٔ DeepSeek Harness هنوز پیش‌نمایش توسعه‌دهندگان است؛ به سایت گفت‌وگوی DeepSeek یا API آن وصل نمی‌شود.

گراف و اطلاعات شبیه‌سازی Flock کجا ذخیره می‌شوند؟

Flock گراف SQLite، بررسی شواهد، آزمایش سناریوها، سابقهٔ اجرا و تصویرسازی‌ها را در پوشهٔ .flock/ در فضای کاری انتخابی تو نگه می‌دارد. سایت Flock این داده‌های پروژه را دریافت نمی‌کند.

۰۷ / حریم خصوصی و داده‌ها

فضای کاری تو، محیط AI خودت

  • بخش‌هایی از منبع و دستورها از طریق نشست فعال و تنظیمات سرویس‌دهندهٔ خودت در محیط AI پردازش می‌شوند. تنظیمات حساب، سیاست مدل، پلن و محدودیت‌های همان محیط برقرار است.
  • ابزار Pythonِ Flock نه به شبکه وصل می‌شود، نه مدلی را صدا می‌زند و نه اطلاعات ورود به محیط AI را می‌خواند. گراف، بررسی شواهد، آزمایش سناریوها، تصویرسازی و گزارش‌ها را در پوشهٔ .flock/ فضای کاری انتخابی ذخیره می‌کند.
  • Flock نه کلید جداگانهٔ API سرویس‌دهنده می‌خواهد، نه کلید Zep و نه حساب Flock. بعضی تنظیمات محیط AI ممکن است اطلاعات ورود مخصوص خودشان را بخواهند.
  • سایت عمومی Flock اطلاعات و راهنمای نصب را نشان می‌دهد. شبیه‌سازی در فضای کاری هر کاربر اجرا می‌شود و سرور سایت منبع‌ها، گراف‌ها یا سابقهٔ اجرای پروژه را دریافت نمی‌کند.
  • قبل از به‌اشتراک‌گذاشتن منبع‌ها یا گراف‌های ساخته‌شده، از پشتیبان‌گیری و تنظیمات Git فضای کاری‌ات مطمئن شو.

۰۸ / رفع مشکل

اگر چیزی درست کار نکرد

محیط AI، Flock را پیدا نمی‌کند

مطمئن شو بسته درست نصب شده و محیط AI را دوباره باز کن. در Codex این را بررسی کن: codex plugin list؛ در Claude Code این را ببین: /plugin؛ در Gemini CLI و Qwen Code فهرست افزونه‌ها را ببین. پلاگین DeepSeek Harness هنوز پیش‌نمایش توسعه‌دهندگان است.

نسخهٔ Python نصب نیست یا قدیمی است

Python نسخهٔ ۳٫۱۱ یا جدیدتر را نصب کن و مطمئن شو دستور python در محیط اجرای AI کار می‌کند. برای گراف یا پایگاه داده لازم نیست بستهٔ دیگری نصب کنی.

بررسی گراف می‌گوید منبعی پیدا نمی‌شود
